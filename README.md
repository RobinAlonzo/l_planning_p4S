# Créneaux

Outil personnel : convertit un tableau de créneaux en fichier calendrier (.ics), sur ordinateur ou téléphone.

- Accès protégé par mot de passe (contenu chiffré AES-256).
- Les fichiers sont lus uniquement dans le navigateur de l'utilisateur ; rien n'est envoyé ni stocké en ligne.
- Aucun service extérieur n'est contacté.
